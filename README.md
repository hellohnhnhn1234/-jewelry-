# VALLIÈRE — Haute Joaillerie

A two-section cinematic jewellery landing page built with plain HTML, CSS and a small amount of vanilla JavaScript. No frameworks, build step or external dependencies.

## View locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python -m http.server 8899
```

Then visit `http://127.0.0.1:8899/`.

## Structure

- `index.html` — hero, story section, navigation and film controls
- `style.css` — layout, fluid typography, responsive rules and CSS animations
- `script.js` — mobile menu and background-film toggle
- `assets/` — films, poster frames, fonts, logo and favicon
